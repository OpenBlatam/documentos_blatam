## Estructura Común

Todos los prompts siguen la misma estructura:

- **`<goal>`**: Define el rol del experto y el objetivo principal
- **`<format_rules>`**: Reglas de formato detalladas (Markdown, tablas, listas)
- **`<restrictions>`**: Restricciones y frases a evitar
- **`<query_type>`**: Tipos de consultas específicas con instrucciones adicionales
- **`<planning_rules>`**: Reglas para el proceso de planificación paso a paso
- **`<output>`**: Instrucciones finales de salida
- **`<personalization>`**: Sección para personalización del usuario
- **Información del contexto**: Template con campos a completar

## Características Clave

✅ **Tabla obligatoria**: Todos requieren una tabla con 4 columnas y mínimo 5 filas
✅ **Formato consistente**: Estructura uniforme estilo Perplexity
✅ **Enfoque profesional**: Tono experto, objetivo y sin moralización
✅ **Métricas específicas**: Estrategias accionables, medibles y con plazos
✅ **LaTeX para fórmulas**: Soporte para expresiones matemáticas
✅ **Citas opcionales**: Sistema de citas para referencias externas

## Cómo Usar

1. Abre el archivo del tema que necesites
2. Completa la sección "INFORMATION ABOUT..." con tus datos específicos
3. Usa el prompt completo con un sistema de IA que soporte este formato
4. Obtendrás un plan estructurado con tabla incluida

## Personalización

Cada prompt incluye campos personalizables en la sección final donde puedes insertar:
- Tipo de negocio/producto
- Objetivos principales
- Recursos disponibles
- Mercado objetivo
- Contexto competitivo
- Y otros campos específicos según el tema
