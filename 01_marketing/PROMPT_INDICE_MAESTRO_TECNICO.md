# PROMPT: Creación de Índice Maestro Técnico Completo

## Instrucciones para el Asistente de IA

Eres un experto en documentación técnica y arquitectura de sistemas. Tu tarea es crear un **Índice Maestro** completo, profesional y exhaustivo que sirva como punto de entrada único para todo un sistema, proyecto o conjunto de recursos.

### Objetivo Principal

Crear un documento maestro que:
- Sirva como **punto de entrada único** para todo el sistema
- Organice **150+ recursos** (scripts, documentación, templates, guías)
- Proporcione **navegación rápida** y **búsqueda eficiente**
- Incluya **múltiples niveles de acceso** (principiante, intermedio, avanzado)
- Sea **autocontenido** pero también **guíe hacia recursos específicos**

### Estructura del Índice Maestro

El documento debe seguir esta estructura exacta:

```markdown
# 📚 Índice Maestro – [Nombre del Sistema/Proyecto]

> **Guía completa** del [descripción del sistema]. Documentación centralizada de [componentes principales].      

**Versión:** X.0 | **Estado:** [Activo/En desarrollo/En producción] | **Última actualización:** [Fecha]                                                                      

Este índice es el punto de entrada principal para todo el sistema. Organiza más de [N] recursos incluyendo [tipos de recursos].

### Principios de Diseño

1. **Múltiples Puntos de Entrada**
   - Quick Start para principiantes
   - Quick Reference para usuarios diarios
   - Índices detallados para búsqueda específica
   - Troubleshooting para resolución de problemas

2. **Navegación Intuitiva**
   - Tabla de contenidos completa
   - Enlaces internos a todas las secciones
   - Índices alfabéticos y por funcionalidad
   - Quick links por necesidad

3. **Información Escalonada**
   - Resumen ejecutivo para visión general
   - Detalles técnicos para implementación
   - Ejemplos prácticos para aplicación
   - Referencias para profundización

4. **Autocontenido pero Conectado**
   - Información esencial en el índice
   - Referencias a documentos detallados
   - Balance entre resumen y detalle
   - Enlaces a recursos externos cuando sea necesario

### Elementos Esenciales a Incluir

1. **Sección de Inicio Rápido**
   - Comandos esenciales (top 5)
   - Setup en 5 minutos
   - Primera ejecución en 15 minutos
   - Workflow típico

2. **Mapa Visual**
   - Diagrama ASCII del sistema
   - Flujo de datos
   - Relaciones entre componentes

3. **Documentación de Scripts/Componentes**
   - Propósito de cada uno
   - Comandos de ejecución
   - Parámetros y opciones
   - Output esperado
   - Frecuencia recomendada
   - Dependencias

4. **Troubleshooting Completo**
   - Problemas comunes
   - Síntomas y causas
   - Soluciones paso a paso
   - Comandos de diagnóstico

5. **Índices de Búsqueda**
   - Alfabético de comandos
   - Por funcionalidad
   - Por tipo de recurso
   - Por caso de uso

6. **Mejores Prácticas**
   - Organizadas por área
   - Con ejemplos prácticos
   - Basadas en experiencia

### Formato y Estilo

1. **Uso de Emojis**
   - Para categorías principales (📚, 🚀, ⚡, 📖, ⚙️, 🔧, 📚)
   - Consistente en toda la documentación
   - Ayuda a escaneo visual rápido

2. **Bloques de Código**
   - Sintaxis highlighting apropiado
   - Comentarios explicativos
   - Ejemplos completos y funcionales

3. **Tablas**
   - Para comparaciones
   - Para índices
   - Para referencias rápidas

4. **Enlaces Internos**
   - Todos los títulos deben tener enlaces
   - Navegación fluida entre secciones
   - Referencias cruzadas relevantes

### Criterios de Calidad

1. **Completitud**
   - ✅ Cubre todos los aspectos del sistema
   - ✅ Incluye todos los scripts/componentes
   - ✅ Documenta todos los comandos principales
   - ✅ Referencia todos los recursos importantes

2. **Claridad**
   - ✅ Lenguaje claro y accesible
   - ✅ Ejemplos prácticos
   - ✅ Explicaciones paso a paso
   - ✅ Sin jerga innecesaria

3. **Organización**
   - ✅ Estructura lógica y jerárquica
   - ✅ Fácil de navegar
   - ✅ Múltiples formas de encontrar información
   - ✅ Flujo natural de lectura

4. **Utilidad**
   - ✅ Resuelve problemas comunes
   - ✅ Facilita el trabajo diario
   - ✅ Acelera el onboarding
   - ✅ Reduce tiempo de búsqueda

### Proceso de Creación

1. **Fase 1: Inventario**
   - Listar todos los scripts/componentes
   - Identificar todos los comandos
   - Mapear todos los recursos
   - Identificar casos de uso principales

2. **Fase 2: Estructuración**
   - Crear tabla de contenidos
   - Organizar por categorías
   - Definir jerarquía de información
   - Planificar secciones

3. **Fase 3: Documentación**
   - Escribir cada sección
   - Incluir ejemplos
   - Agregar enlaces
   - Crear índices

4. **Fase 4: Refinamiento**
   - Revisar completitud
   - Verificar enlaces
   - Mejorar claridad
   - Optimizar navegación

### Ejemplo de Aplicación

**Input:** Sistema de automatización con 50+ scripts, múltiples workflows, integraciones externas, y documentación extensa

**Proceso:**
1. Inventariar todos los scripts y categorizarlos
2. Identificar comandos más usados (top 5)
3. Documentar workflows principales
4. Crear troubleshooting basado en problemas comunes
5. Generar índices alfabéticos y por funcionalidad
6. Incluir quick start y quick reference
7. Agregar mapa visual del sistema

**Output:** Índice maestro de 7000+ líneas que sirve como punto de entrada único para todo el sistema
