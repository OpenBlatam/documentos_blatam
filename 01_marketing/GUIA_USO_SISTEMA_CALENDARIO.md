## Introducción

El **Sistema de Calendario de Contenido de Redes Sociales** es un prompt completo diseñado para sistemas de inteligencia artificial que permite generar calendarios de contenido estratégicos, optimizados y listos para implementar en múltiples plataformas de redes sociales.

Este sistema está diseñado para:
- Crear calendarios de contenido estratégicos y optimizados
- Alinear contenido con objetivos de negocio y comportamiento de audiencia
- Optimizar para múltiples plataformas de redes sociales
- Generar contenido específico, accionable y listo para implementar

## Cómo Usar el Sistema

### Paso 1: Preparar el Contexto

Antes de usar el sistema, necesitas tener:

- **Brand Guidelines**: Guías de marca, voz, tono, valores
- **Content Themes**: Temas de contenido, pilares de contenido
- **Campaign Objectives**: Objetivos de campaña, KPIs
- **Audience Insights**: Investigación de audiencia, comportamiento
- **Platform Best Practices**: Mejores prácticas por plataforma

### Paso 2: Copiar el Sistema de Prompt

1. Abre el archivo `SISTEMA_CALENDARIO_CONTENIDO_REDES_SOCIALES.md`
2. Copia todo el contenido desde `<goal>` hasta `</personalization>`
3. Pega el contenido en tu sistema de IA (ChatGPT, Claude, etc.)

### Paso 3: Agregar el Brief de Contenido

Después del sistema de prompt, agrega tu brief de contenido:

```
---

BRIEF DE CONTENIDO:

- Marca: [Nombre de la marca]
- Plataformas: [Instagram, Facebook, LinkedIn, etc.]
- Período: [Semanal, Mensual, Trimestral]
- Objetivos: [Awareness, Engagement, Conversiones]
- Temas de Contenido: [Lista de temas]
- Audiencia: [Descripción de la audiencia]
- [Cualquier otra información relevante]
```

### Paso 4: Generar el Calendario

El sistema de IA generará un calendario completo que incluye:
- Introducción estratégica
- Estrategia de contenido
- Calendario detallado en formato tabla
- Recomendaciones por plataforma
- Estrategia de hashtags
- Métricas y KPIs

## Estructura del Sistema

### 1. Objetivo del Sistema (`<goal>`)

Define el rol y propósito del sistema. Establece que el sistema es un "Social Media Content Calendar Strategist" profesional.

### 2. Reglas de Formato (`<format_rules>`)

Instrucciones detalladas sobre cómo formatear el calendario:
- Inicio del calendario (sin headers)
- Encabezados y secciones
- Formato de listas
- Tablas para calendarios
- Énfasis y destacados
- Temas de contenido y pilares
- Tiempo y frecuencia
- Hashtags y etiquetas
- Citaciones

### 3. Restricciones (`<restrictions>`)

Lista completa de lo que NO debe hacer el sistema:
- No usar lenguaje de moralización
- No comenzar con headers
- No repetir contenido con copyright
- No usar emojis en el cuerpo
- No terminar con preguntas
- Y más...

### 4. Tipos de Consulta (`<query_type>`)

Diferentes tipos de calendarios que el sistema puede crear:
- Semanal
- Mensual
- Específico de campaña
- Multi-plataforma
- Basado en pilares
- Estacional
- Basado en eventos
- Evergreen
- Específico de plataforma
- Estrategia de mezcla

### 5. Reglas de Planificación (`<planning_rules>`)

Proceso estratégico de planificación:
- Proceso de planificación estratégica (10 pasos)
- Consideraciones de estrategia de contenido
- Estrategia de tiempo y frecuencia
- Aseguramiento de calidad
- Consideraciones estratégicas avanzadas
- Casos especiales

### 6. Especificaciones de Salida (`<output>`)

Requisitos detallados de la salida:
- Estructura del calendario (10 secciones)
- Estándares de calidad
- Listo para ejecución
- Profundidad estratégica
- Adaptabilidad
- Manejo de errores
- Requisitos de citación
- Checklist final

### 7. Personalización (`<personalization>`)

Sección para personalizaciones específicas del usuario.

## Ejemplos de Uso

### Ejemplo 1: Calendario Semanal para Instagram

```
BRIEF:
- Marca: Tienda de ropa sostenible
- Plataforma: Instagram
- Período: Semana del 20-26 de mayo
- Objetivos: Engagement y awareness
- Temas: Sostenibilidad, moda, lifestyle
- Audiencia: Mujeres 25-40 años, conscientes del medio ambiente
```

**Resultado esperado:**
- Calendario diario con 1-2 posts por día
- Horarios optimizados (11 AM - 1 PM)
- Mix de contenido: educativo (30%), entretenimiento (25%), promocional (20%)
- Hashtags específicos por post
- Captions preview

### Ejemplo 2: Calendario Mensual Multi-Plataforma

```
BRIEF:
- Marca: SaaS B2B
- Plataformas: LinkedIn, Twitter/X, Facebook
- Período: Junio 2025
- Objetivos: Lead generation y thought leadership
- Temas: Tecnología, casos de éxito, webinars
- Audiencia: Decision makers B2B, CTOs, CEOs
```

**Resultado esperado:**
- Calendario coordinado en 3 plataformas
- Contenido repurposing entre plataformas
- Horarios específicos por plataforma
- Estrategia de contenido series
- Métricas B2B específicas

### Ejemplo 3: Calendario de Lanzamiento de Producto

```
BRIEF:
- Marca: Startup de tecnología
- Plataformas: Todas las principales
- Período: 4 semanas (pre-lanzamiento, lanzamiento, post-lanzamiento)
- Objetivos: Awareness, conversiones, UGC
- Temas: Producto, características, testimonios
- Audiencia: Early adopters, tech enthusiasts
```

**Resultado esperado:**
- Calendario en 3 fases
- Contenido teaser pre-lanzamiento
- Estrategia de lanzamiento día D
- Contenido post-lanzamiento
- Campaña UGC integrada

## Mejores Prácticas

### ✅ DO (Hacer)

1. **Proporciona contexto completo**
   - Incluye toda la información relevante en el brief
   - Menciona objetivos claros y medibles
   - Especifica restricciones o requisitos especiales

2. **Sé específico con la audiencia**
   - Describe demografía, psicografía, comportamiento
   - Menciona plataformas preferidas de la audiencia
   - Incluye insights de investigación si los tienes

3. **Define objetivos claros**
   - Awareness, engagement, conversiones, etc.
   - KPIs específicos si los tienes
   - Prioridades si hay múltiples objetivos

4. **Revisa y ajusta**
   - El sistema genera un calendario base
   - Revisa y ajusta según tus necesidades
   - Aprovecha el checklist de calidad incluido

### ❌ DON'T (No Hacer)

1. **No uses briefs genéricos**
   - Evita "crea un calendario para mi marca"
   - Proporciona contexto específico

2. **No ignores las restricciones**
   - El sistema tiene restricciones por una razón
   - Respeta las limitaciones del sistema

3. **No esperes perfección inmediata**
   - Revisa y ajusta el calendario generado
   - Personaliza según tu marca y audiencia

4. **No copies contenido directamente**
   - El sistema genera ideas, no contenido final
   - Adapta y personaliza para tu marca

## Preguntas Frecuentes

### ¿Puedo usar este sistema con cualquier IA?

Sí, el sistema está diseñado para funcionar con cualquier sistema de IA que pueda procesar instrucciones complejas en formato de prompt. Ha sido probado con:
- ChatGPT (GPT-4, GPT-3.5)
- Claude (Anthropic)
- Gemini (Google)
- Otros sistemas avanzados

### ¿Necesito conocimientos técnicos?

No, el sistema está diseñado para ser usado por cualquier persona. Solo necesitas:
- Copiar y pegar el prompt
- Agregar tu brief de contenido
- Revisar y ajustar el resultado

### ¿Puedo modificar el sistema?

Sí, puedes modificar el sistema según tus necesidades. Sin embargo, se recomienda:
- Mantener la estructura principal
- No eliminar restricciones importantes
- Probar cambios en pequeños ajustes primero

### ¿Qué hago si el calendario generado no es lo que necesito?

1. Revisa tu brief - ¿fue lo suficientemente específico?
2. Ajusta los objetivos o temas
3. Proporciona más contexto sobre tu audiencia
4. Especifica mejor los requisitos de formato
5. Usa ejemplos de contenido que te gusten

### ¿Puedo usar este sistema para múltiples marcas?

Sí, el sistema es genérico y puede adaptarse a cualquier marca. Solo necesitas cambiar el brief de contenido para cada marca.

### ¿El sistema genera contenido real o solo estructura?

El sistema genera:
- Estructura completa del calendario
- Temas y tópicos específicos
- Captions preview (ejemplos)
- Estrategias de hashtags
- Recomendaciones de timing

NO genera:
- Contenido final listo para publicar (necesitas adaptarlo)
- Imágenes o visuales
- Contenido con copyright

## Solución de Problemas

### Problema: El calendario no incluye todas las plataformas

**Solución:**
- Verifica que mencionaste todas las plataformas en el brief
- Especifica claramente "Multi-plataforma" en el brief
- Menciona cada plataforma individualmente

### Problema: Los horarios no son correctos para mi zona horaria

**Solución:**
- Especifica tu zona horaria en el brief
- Menciona "horarios en [tu zona horaria]"
- El sistema ajustará las recomendaciones

### Problema: El contenido no se alinea con mi marca

**Solución:**
- Proporciona más detalles sobre la voz y tono de tu marca
- Incluye ejemplos de contenido que te gusta
- Especifica valores y mensajes clave de la marca

### Problema: El calendario es demasiado genérico

**Solución:**
- Proporciona más contexto específico
- Incluye insights de audiencia detallados
- Menciona campañas o eventos específicos
- Especifica productos o servicios concretos

### Problema: El formato no es el que necesito

**Solución:**
- El sistema genera en formato Markdown con tablas
- Puedes copiar las tablas a Excel o Google Sheets
- Puedes convertir Markdown a otros formatos
- Especifica en el brief si necesitas un formato diferente
