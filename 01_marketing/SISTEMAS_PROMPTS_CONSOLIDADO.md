# 📚 Sistemas de Prompts Consolidados

> **Colección completa** de todos los sistemas de prompts creados para diferentes casos de uso en marketing y creación de contenido.

**Versión:** 2.0 | **Estado:** Activo | **Última actualización:** Mayo 2025

Este documento contiene todos los sistemas de prompts desarrollados, cada uno optimizado para un propósito específico y siguiendo la misma estructura profesional.

---

## 🚀 Inicio Rápido

### ¿Qué encontrarás aquí?

Este documento contiene **sistemas de prompts completos** para diferentes tareas de marketing y creación de contenido. Cada sistema incluye:

- ✅ **Instrucciones detalladas** para el modelo de IA
- ✅ **Reglas de formato** específicas para cada tipo de contenido
- ✅ **Variantes de diseño** para diferentes estilos y audiencias
- ✅ **Especificaciones técnicas** para Word, PDF, Excel y Markdown
- ✅ **Guías prácticas** y ejemplos de implementación

### Sistemas Disponibles

| Sistema | Propósito | Variantes Disponibles |
|---------|-----------|----------------------|
| 🔍 **Perplexity** | Búsqueda y respuestas informativas | 1 variante estándar |
| 🎬 **Videos UGC** | Creación de videos de contenido generado por usuarios | Múltiples formatos |
| ✍️ **Creación de Contenido** | Artículos, posts, copywriting, landing pages | 6 variantes (Creativo, Alto Impacto, Corporativo, Minimalista, Startup, Editorial) |
| 📅 **Calendario Social Media** | Planificación de contenido para redes sociales | Estrategias por plataforma |
| 🎨 **Diseño Gráfico** | Diseño visual y branding | Múltiples estilos |
| 💼 **Ventas y Cierre** | Estrategias de ventas, scripts, objection handling | 9 variantes especializadas |

### Cómo Usar Este Documento

1. **Identifica tu necesidad:** ¿Qué tipo de contenido necesitas crear?
2. **Selecciona el sistema:** Busca el sistema correspondiente en el índice
3. **Elige la variante:** Usa la guía rápida para seleccionar la variante adecuada
4. **Copia el prompt completo:** Incluye todas las secciones del sistema elegido
5. **Personaliza si es necesario:** Ajusta según tus necesidades específicas

### 💡 Tips Importantes

- **Cada sistema es autocontenido:** Incluye todas las instrucciones necesarias
- **Las variantes son intercambiables:** Puedes mezclar elementos de diferentes variantes
- **Los formatos son flexibles:** Adapta las especificaciones según tus herramientas
- **Siempre revisa el output:** Ajusta y refina según sea necesario
