# 🎯 Estrategias por Tipo de Producto

> **Guías específicas de outreach adaptadas a diferentes tipos de productos y servicios**

## 🛠️ Productos SaaS (Software as a Service)

### Características del Producto
- Software en la nube
- Suscripción mensual/anual
- Funcionalidades técnicas
- Casos de uso específicos

### Estrategia de Outreach

**Targeting:**
- Desarrolladores
- Tech enthusiasts
- Product managers
- CTOs/Technical leads

**Mensaje clave:**
- Eficiencia y productividad
- Características técnicas
- Integraciones
- ROI del tiempo ahorrado

**Tipo de contenido:**
- Tutoriales técnicos
- Comparaciones con alternativas
- Casos de uso específicos
- Integraciones y workflows

**Compensación:**
- Acceso premium gratuito
- Comisión por referidos (10-20%)
- Pago fijo ($200-$500)
- Híbrido (acceso + comisión)

**Plataformas:**
- YouTube (tutoriales)
- Twitter/X (tech community)
- LinkedIn (profesional)
- GitHub (desarrolladores)

**Ejemplo de mensaje:**
```
Hola [Nombre],

Vi tu contenido sobre [tema técnico] y me encantó tu enfoque.

[Producto] es una herramienta que [descripción técnica breve] y creo que podría ser perfecta para tu audiencia de desarrolladores.

¿Te interesa probarlo gratis? Sin compromiso, solo para que veas si te gusta.

Saludos,
[Tu nombre]
```

## 🎯 Adaptación de Estrategia

### Pasos para Adaptar

1. **Identifica tipo de producto**
   - ¿Qué es exactamente?
   - ¿Cómo se usa?
   - ¿Quién lo usa?

2. **Define audiencia objetivo**
   - ¿Quién necesita esto?
   - ¿Dónde están?
   - ¿Qué consumen?

3. **Elige plataformas**
   - ¿Dónde está tu audiencia?
   - ¿Qué formato funciona?
   - ¿Dónde hay menos competencia?

4. **Ajusta mensaje**
   - ¿Qué valor ofrece?
   - ¿Qué problemas resuelve?
   - ¿Por qué es único?

5. **Define compensación**
   - ¿Qué puedes ofrecer?
   - ¿Qué funciona para este tipo?
   - ¿Cuál es el presupuesto?
