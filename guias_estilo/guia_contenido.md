# Guía de Estilo para Contenido OpenBlatam

## Propósito

Esta guía establece los estándares de calidad y estilo para todo el contenido generado en la plataforma OpenBlatam, asegurando consistencia, profesionalismo y efectividad en la comunicación.

## Principios Fundamentales

### Voz y Tono

- **Profesional pero accesible**: Técnicamente preciso pero comprensible
- **Centrado en el usuario**: Resuelve problemas reales del usuario
- **Directo y claro**: Evita lenguaje innecesariamente complejo
- **Consistente**: Mantiene la misma voz en todos los documentos

### Estructura del Contenido

#### Introducciones
- Comenzar con una declaración que capture la atención
- Establecer claramente el valor para el lector
- Proporcionar una vista previa de los puntos principales

#### Cuerpo del Contenido
- Usar encabezados jerárquicos (H2, H3)
- Párrafos cortos (3-5 líneas máximo)
- Listas para información relacionada
- Tablas para comparaciones

#### Conclusiones
- Resumir puntos clave
- Proporcionar siguiente paso claro
- Reforzar el valor principal

### Terminología Técnica

- **Definir términos nuevos** en su primer uso
- **Usar términos consistentemente** en todo el contenido
- **Evitar jerga innecesaria** cuando existan alternativas claras

### Estructuras de Datos

Para documentación de APIs:

{
  "campo_obligatorio": "tipo",
  "campo_opcional": "tipo (opcional)",
  "descripcion": "explicación clara del propósito"
}


## Elementos Visuales

### Tablas

Usar tablas Markdown para:
- Comparaciones de características
- Especificaciones técnicas
- Parámetros de API

### Listas

**Listas no ordenadas** para:
- Características
- Beneficios
- Elementos relacionados

**Listas ordenadas** para:
- Pasos de procedimiento
- Procesos secuenciales
- Jerarquías

## Convenciones de Escritura

### Lenguaje

- **Español neutro**: Evitar regionalismos
- **Active voice**: Preferir "el sistema procesa" sobre "es procesado por el sistema"
- **Persona adecuada**: Usar "usted" para documentación técnica

### Puntuación y Formato

- **Títulos**: Capitalización de Título
- **Encabezados**: Formato sentencia
- **Enlaces**: Texto descriptivo, no "haz clic aquí"

## Proceso de Revisión

### Checklist de Calidad

- [ ] El título refleja accuratamente el contenido
- [ ] La introducción engancha y establece valor
- [ ] La estructura es lógica y fácil de seguir
- [ ] El lenguaje es claro y conciso
- [ ] Los ejemplos son relevantes y funcionan
- [ ] No hay errores técnicos
- [ ] Las llamadas a la acción son claras

### Métricas de Éxito

- **Tiempo de lectura**: Objetivo 5-10 minutos
- **Puntuación de legibilidad**: > 60 en índices estándar
- **Completitud técnica**: Cubre todos los aspectos prometidos
