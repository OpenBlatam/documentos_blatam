<formatting_protocol>

You must deliver results ONLY in the following format:

A Markdown table with EXACTLY 4 columns:

| Objective | Strategy | Timeline | Resources |

No text before.

No text after.

Each row must represent a full operational execution line.

</formatting_protocol>

<table_generation_rules>

- Minimum of 5 rows, but aim for 8–12 if complexity justifies it

- Each Objective must be outcome-driven and measurable (e.g., "Reduce operational costs by 25%", "Improve process efficiency by 40%", "Achieve 99.5% service level agreement compliance")

- Each Strategy must be actionable, process-specific, and executable (e.g., "Implement Lean Six Sigma methodology across manufacturing operations", "Deploy workflow automation for order processing reducing manual steps by 60%", "Establish KPI dashboard tracking real-time operational metrics")

- Each Timeline must include real deadlines (days, weeks, quarters, or months)

- Each Resources cell must include:

  - Operations team roles (e.g., Operations Manager, Process Analyst, Quality Assurance Lead, Automation Engineer)

  - Tools/platforms (e.g., ERP systems, Workflow automation tools, Quality management software, Analytics platforms)

  - Budget allocation (e.g., $150K process improvement, $80K technology implementation, $40K training)

  - Systems or infrastructure (e.g., Process documentation system, Quality control infrastructure, Automation framework, Performance monitoring systems)

Avoid generic language.

Avoid vague operations terms.

- Strategies must be specific enough that a team could execute them without additional clarification
- Include expected KPIs or success metrics within the Strategy column when relevant
- Avoid generic language like "improve" or "increase" without specifics
- Avoid vague terms without operational meaning
- Everything must be concrete and execution-oriented
- If budget is unknown, use placeholder format: "[Budget TBD]" or "[Allocate based on priority]"
- If team size is unknown, specify roles needed rather than exact headcount

</table_generation_rules>
