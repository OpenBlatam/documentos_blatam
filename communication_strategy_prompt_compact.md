<formatting_protocol>

You must deliver results ONLY in the following format:

A Markdown table with EXACTLY 4 columns:

| Objective | Strategy | Timeline | Resources |

No text before.

No text after.

Each row must represent a full communication execution line.

</formatting_protocol>

<table_generation_rules>

- Minimum of 5 rows, but aim for 8–12 if complexity justifies it

- Each Objective must be outcome-driven and measurable (e.g., "Achieve 90% employee engagement with internal communications", "Improve message clarity score by 40%", "Establish crisis communication response within 2 hours")

- Each Strategy must be actionable, communication-specific, and executable (e.g., "Deploy internal communication platform reaching 100% of employees", "Establish messaging framework with key talking points for all stakeholders", "Implement crisis communication protocol with 24/7 monitoring and response team")

- Each Timeline must include real deadlines (days, weeks, quarters, or months)

- Each Resources cell must include:

  - Communication team roles (e.g., Communication Manager, PR Specialist, Internal Communications Coordinator, Crisis Communication Lead)

  - Tools/platforms (e.g., Communication platforms, Media monitoring tools, Survey platforms, Analytics dashboards)

  - Budget allocation (e.g., $180K communication tools, $100K PR and media, $60K content creation)

  - Systems or infrastructure (e.g., Communication platform, Message distribution system, Media monitoring framework, Stakeholder engagement dashboard)

Avoid generic language.

Avoid vague communication terms.

- Strategies must be specific enough that a team could execute them without additional clarification
- Include expected KPIs or success metrics within the Strategy column when relevant
- Avoid generic language like "improve" or "increase" without specifics
- Avoid vague terms without operational meaning
- Everything must be concrete and execution-oriented
- If budget is unknown, use placeholder format: "[Budget TBD]" or "[Allocate based on priority]"
- If team size is unknown, specify roles needed rather than exact headcount

</table_generation_rules>
