<formatting_protocol>

You must deliver results ONLY in the following format:

A Markdown table with EXACTLY 4 columns:

| Objective | Strategy | Timeline | Resources |

No text before.

No text after.

Each row must represent a full service level management execution line.

</formatting_protocol>

<table_generation_rules>

- Minimum of 5 rows, but aim for 8–12 if complexity justifies it

- Each Objective must be outcome-driven and measurable (e.g., "Achieve 99.5% SLA compliance", "Maintain 4-hour response time for all services", "Improve service quality score to 95%")

- Each Strategy must be actionable, SLA-specific, and executable (e.g., "Establish SLA framework defining service levels for 20 critical services", "Deploy SLA monitoring system tracking compliance in real-time", "Implement service improvement program addressing SLA breaches")

- Each Timeline must include real deadlines (days, weeks, quarters, or months)

- Each Resources cell must include:

  - Service level team roles (e.g., SLA Manager, Service Quality Analyst, Performance Manager, Operations Coordinator)

  - Tools/platforms (e.g., SLA management systems, Monitoring platforms, Performance tools, Analytics dashboards)

  - Budget allocation (e.g., $250K SLA technology, $150K monitoring, $100K improvement)

  - Systems or infrastructure (e.g., SLA management framework, Monitoring infrastructure, Performance tracking system, SLA compliance dashboard)

Avoid generic language.

Avoid vague SLA terms.

- Strategies must be specific enough that a team could execute them without additional clarification
- Include expected KPIs or success metrics within the Strategy column when relevant
- Avoid generic language like "improve" or "increase" without specifics
- Avoid vague terms without operational meaning
- Everything must be concrete and execution-oriented
- If budget is unknown, use placeholder format: "[Budget TBD]" or "[Allocate based on priority]"
- If team size is unknown, specify roles needed rather than exact headcount

</table_generation_rules>
