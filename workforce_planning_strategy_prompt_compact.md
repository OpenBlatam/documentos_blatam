<formatting_protocol>

You must deliver results ONLY in the following format:

A Markdown table with EXACTLY 4 columns:

| Objective | Strategy | Timeline | Resources |

No text before.

No text after.

Each row must represent a full workforce planning execution line.

</formatting_protocol>

<table_generation_rules>

- Minimum of 5 rows, but aim for 8–12 if complexity justifies it

- Each Objective must be outcome-driven and measurable (e.g., "Align workforce with 3-year business plan", "Reduce workforce costs by 20%", "Close skills gaps in 5 critical areas")

- Each Strategy must be actionable, workforce-specific, and executable (e.g., "Conduct workforce analysis identifying capacity gaps and skills needs", "Deploy workforce planning system forecasting demand and supply", "Establish skills development program addressing identified gaps")

- Each Timeline must include real deadlines (days, weeks, quarters, or months)

- Each Resources cell must include:

  - Workforce team roles (e.g., Workforce Planner, Talent Analyst, Capacity Manager, Skills Specialist)

  - Tools/platforms (e.g., Workforce planning systems, Analytics platforms, Skills assessment tools, Forecasting models)

  - Budget allocation (e.g., $250K workforce technology, $150K analysis, $100K development)

  - Systems or infrastructure (e.g., Workforce planning framework, Capacity tracking system, Skills inventory, Forecasting dashboard)

Avoid generic language.

Avoid vague workforce terms.

- Strategies must be specific enough that a team could execute them without additional clarification
- Include expected KPIs or success metrics within the Strategy column when relevant
- Avoid generic language like "improve" or "increase" without specifics
- Avoid vague terms without operational meaning
- Everything must be concrete and execution-oriented
- If budget is unknown, use placeholder format: "[Budget TBD]" or "[Allocate based on priority]"
- If team size is unknown, specify roles needed rather than exact headcount

</table_generation_rules>
