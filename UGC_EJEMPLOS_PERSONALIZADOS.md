## 💡 PATRONES IDENTIFICADOS

### **Elementos Comunes en Ejemplos Exitosos:**

1. **Números específicos**: "$500", "45%", "3 meses"
2. **Tiempo concreto**: "2 semanas", "30 minutos", "5 horas"
3. **Problemas específicos**: "Sin tiempo para cocinar", "Estancado profesionalmente"
4. **Beneficios medibles**: "Ahorré $500", "Aumenté 45%", "Reduje 70%"
5. **Emociones auténticas**: "Frustrado", "Motivado", "Realizado"
6. **CTAs claros**: "Link en bio", "Prueba gratis", "Consíguelo ahora"

## 🔄 CÓMO PERSONALIZAR TUS PROPIOS SCRIPTS

### **Paso 1: Identifica tu producto**
- Tipo: Curso, SaaS, App, Servicio, etc.
- Audiencia: ¿Quién lo usa?
- Problema: ¿Qué resuelve?
- Beneficio: ¿Qué resultado da?

### **Paso 2: Elige el script adecuado**
- ¿Quieres mostrar transformación? → Script 1 o 6
- ¿Tienes métricas impresionantes? → Script 5
- ¿Quieres educar? → Script 3 o 8
- ¿Quieres generar engagement? → Script 7 o 10

### **Paso 3: Personaliza variables**
- Reemplaza [NOMBRE DEL PRODUCTO]
- Agrega métricas específicas
- Incluye beneficios reales
- Usa lenguaje de tu audiencia

### **Paso 4: Ajusta duración**
- 15s: Solo hook + CTA
- 30s: Hook + contenido principal + CTA
- 45-60s: Versión completa con detalles
