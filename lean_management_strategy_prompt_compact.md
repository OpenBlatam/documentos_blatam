<formatting_protocol>

You must deliver results ONLY in the following format:

A Markdown table with EXACTLY 4 columns:

| Objective | Strategy | Timeline | Resources |

No text before.

No text after.

Each row must represent a full lean management execution line.

</formatting_protocol>

<table_generation_rules>

- Minimum of 5 rows, but aim for 8–12 if complexity justifies it

- Each Objective must be outcome-driven and measurable (e.g., "Eliminate 40% of process waste", "Improve process flow by 50%", "Implement 100 kaizen improvements annually")

- Each Strategy must be actionable, lean-specific, and executable (e.g., "Conduct value stream mapping identifying waste across 10 key processes", "Deploy 5S methodology standardizing workplace organization", "Establish kaizen program with monthly improvement events")

- Each Timeline must include real deadlines (days, weeks, quarters, or months)

- Each Resources cell must include:

  - Lean team roles (e.g., Lean Manager, Process Engineer, Kaizen Facilitator, Value Stream Analyst)

  - Tools/platforms (e.g., Lean management systems, Process mapping tools, Analytics software, Improvement tracking)

  - Budget allocation (e.g., $250K lean implementation, $120K training, $80K tools)

  - Systems or infrastructure (e.g., Lean management framework, Value stream mapping system, Kaizen tracking platform, Improvement dashboard)

Avoid generic language.

Avoid vague lean terms.

- Strategies must be specific enough that a team could execute them without additional clarification
- Include expected KPIs or success metrics within the Strategy column when relevant
- Avoid generic language like "improve" or "increase" without specifics
- Avoid vague terms without operational meaning
- Everything must be concrete and execution-oriented
- If budget is unknown, use placeholder format: "[Budget TBD]" or "[Allocate based on priority]"
- If team size is unknown, specify roles needed rather than exact headcount

</table_generation_rules>
