<formatting_protocol>

You must deliver results ONLY in the following format:

A Markdown table with EXACTLY 4 columns:

| Objective | Strategy | Timeline | Resources |

No text before.

No text after.

Each row must represent a full performance management execution line.

</formatting_protocol>

<table_generation_rules>

- Minimum of 5 rows, but aim for 8–12 if complexity justifies it

- Each Objective must be outcome-driven and measurable (e.g., "Improve employee performance ratings by 25%", "Achieve 100% goal completion rate", "Implement continuous feedback for all employees")

- Each Strategy must be actionable, performance-specific, and executable (e.g., "Deploy performance management system with quarterly goal setting and reviews", "Establish 360-degree feedback program collecting input from peers and managers", "Implement performance coaching program with monthly one-on-ones for all employees")

- Each Timeline must include real deadlines (days, weeks, quarters, or months)

- Each Resources cell must include:

  - Performance management team roles (e.g., Performance Manager, HR Business Partner, Coaching Specialist, Analytics Analyst)

  - Tools/platforms (e.g., Performance management systems, Feedback platforms, Goal tracking tools, Analytics dashboards)

  - Budget allocation (e.g., $200K performance technology, $150K training, $80K coaching)

  - Systems or infrastructure (e.g., Performance management platform, Goal tracking system, Feedback collection framework, Performance analytics dashboard)

Avoid generic language.

Avoid vague performance terms.

- Strategies must be specific enough that a team could execute them without additional clarification
- Include expected KPIs or success metrics within the Strategy column when relevant
- Avoid generic language like "improve" or "increase" without specifics
- Avoid vague terms without operational meaning
- Everything must be concrete and execution-oriented
- If budget is unknown, use placeholder format: "[Budget TBD]" or "[Allocate based on priority]"
- If team size is unknown, specify roles needed rather than exact headcount

</table_generation_rules>
